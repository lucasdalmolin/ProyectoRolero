# Rolero

**Una caja de herramientas para jugar rol.**

Rolero es una plataforma web pensada para que personas que nunca jugaron rol puedan aprender, explorar herramientas y empezar a jugar sin tener que crear una cuenta.

## Estado
Proyecto en etapa de definición. No se seleccionó stack ni se inició la implementación.
