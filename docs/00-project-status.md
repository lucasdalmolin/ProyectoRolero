# Estado del proyecto

**Fase:** planificación de producto.

## Aprobado

- Público inicial: personas que nunca jugaron rol, en Argentina.
- Idioma: español rioplatense natural, con voseo.
- Experiencia web gratuita, sin cuenta obligatoria y sin instalación requerida.
- D&D 5e como primer sistema; contemplar ediciones 2014 y 2024.
