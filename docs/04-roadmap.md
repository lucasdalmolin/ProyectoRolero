# Roadmap

El roadmap es incremental. Las etapas no equivalen a fechas comprometidas.

| Etapa | Objetivo | Estado |
|---|---|---|
| 1. Visión del producto | Acordar identidad, público y principios | Completada en lo esencial |
| 2. Definición del MVP | Inventario, prioridades y alcance | En curso |
| 3. Dominio y contenido | Entidades, reglas, ediciones y licencias | Pendiente |
| 4. Arquitectura técnica | Persistencia, módulos, stack y despliegue | Pendiente |
| 5. UX/UI | Flujos de principiantes y prototipos | Pendiente |
| 6. Implementación | Desarrollo incremental del MVP | Pendiente |
| 7. Validación | Pruebas con usuarios y mejoras | Pendiente |

Actualizar el estado cuando se cierre cada etapa o hito.
